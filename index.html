§1 · THE PROBLEM

Endogeneity: when X is tangled up with the error term

In the model Y = β0 + β1X + u, the error term u contains the effect of every other cause of Y. OLS recovers the causal effect β1 only if X is uncorrelated with u. When it is not, X is endogenous, and OLS converges to the wrong value:

Throughout, β (or β1) denotes the true unstandardized coefficient in the population (the effect of a 1-unit change in X on Y), and β̂ denotes its estimate from a sample. This follows the econometric convention; in APA style, the estimate would be written b, and β would denote a standardized coefficient.

plim β̂OLS = β1 + Cov(X, u)Var(X)

The second term is the bias. If Cov(X, u) = 0, the bias term drops out and plim β̂OLS = β1. X is then exogenous, and OLS is consistent: as n grows, the estimate converges to the causal effect. If the stronger condition E(u | X) = 0 also holds, OLS is unbiased in finite samples. Under homoskedastic errors it is also the most efficient linear unbiased estimator. Everything in the rest of this page is about restoring that condition when it fails.

Where endogeneity comes from

Each endogeneity source below is analyzed in the same three steps. The first step lays out the equations that describe how X and Y are actually produced, including any causes the researcher does not observe. The second step re-expresses the equation for Y as the regression the researcher actually runs, in which everything other than βX ends up in the error term u. The third step asks whether that error term contains something that is also part of X. If it does, Cov(X, u) ≠ 0 and OLS is biased.

Endogeneity source #1: Omitted common causes

An unmeasured variable U drives both X and Y. Ability, for example, raises both schooling and earnings.

Start from the data-generating model (the equations that describe how the values of each variable are actually produced in the population, including causes we never observe). U affects both variables:

Y = βX + δU + ε,    X = γU + v

U is a component of both Y and X, but U is not measured, so the regression of Y on X cannot include it. Everything that is not βX counts as error:

Y = βX + (δU + ε) so u = δU + ε
Cov(X, u) = Cov(γU + v, δU + ε) = γδ·Var(U)

The error term from the regression, u, should just be ε, the random part of Y that has nothing to do with X. Instead, it also includes δU, the part of Y caused by the omitted variable. Because X contains γU and the error contains δU, the two share a component, causing Cov(X, u) ≠ 0.

A concrete case

Let schooling have no effect on earnings (β = 0), let ability be a positive cause of both schooling and earnings (γ = δ = 1), and give each independent source, U, v, and ε, a variance of 1. Then Var(X) = γ²Var(U) + Var(v) = 2, and OLS converges to 0 + 1/2 = 0.5. Because the true effect β = 0, all of that 0.5 is bias.

That is a sizable return to schooling built entirely from ability. OLS would lead us to conclude that a 1-point increase in the schooling variable produces a .5 increase in the earnings variable even though, in reality, increases in schooling have no effect on earnings.

Why this causes bias

People with high U get more X and more Y. The regression sees X and Y rise together and credits X with U's effect. The lab in §3 simulates exactly this setup. Its unobserved variable U affects X through the γ slider and Y through the δ slider. Raising either one strengthens the back-door path X ← U → Y and widens the gap between OLS and the true β. Setting either one to zero closes the path. If the exclusion-violation sliders (φ₁, φ₂) are also at zero, OLS is then consistent for β.

Endogeneity source #2: Simultaneity

Y also causes X. Suppose a researcher hypothesizes that a leader's behavior (X), as rated by team members, is a positive cause of team performance (Y). Team performance may also shape how the leader is rated, so the causal arrow may run in both directions.

Start from the data-generating model. Each variable appears in the other's equation, with independent errors u and e:

Y = βX + u,    X = αY + e

Substitute the first equation into the second and solve for X:

X = α(βX + u) + e, which can be rewritten as X = (αu + e) / (1 − αβ)

Using covariance algebra, we can derive the covariance between X and u as

Cov(X, u) = α·Var(u) / (1 − αβ)
Show how this covariance is derived

1. Split X into its two parts. The solved equation is a weighted sum of u and e:

X = [α / (1 − αβ)]·u + [1 / (1 − αβ)]·e

2. Use the fact that covariance is linear. For constants c and d, Cov(cA + dB, C) = c·Cov(A, C) + d·Cov(B, C). So

Cov(X, u) = [α / (1 − αβ)]·Cov(u, u) + [1 / (1 − αβ)]·Cov(e, u)

3. Simplify the two covariances. A variable's covariance with itself is its variance, so Cov(u, u) = Var(u). The two errors are independent, so Cov(e, u) = 0. The second term drops out, leaving Cov(X, u) = α·Var(u) / (1 − αβ).

What the pieces mean. α is how strongly Y feeds back into X; if α = 0, there is no reverse causation, the covariance is zero, and OLS is fine. Var(u) is how much the outcome variable's error varies; the larger it is, the more of it flows back into X. 1 / (1 − αβ) is the feedback multiplier: a change in u moves Y, which moves X, which moves Y again, and this term adds up all of those rounds. It equals 1 when αβ = 0, as in the concrete case below, where β = 0.

The outcome variable's own error u is now part of X.

A concrete case

Let leader behavior have no effect on team performance (β = 0), let team performance be a positive cause of the leader's rating (α = 1), and give each independent source, u and e, a variance of 1. Then X = u + e, so Var(X) = Var(u) + Var(e) = 2 and Cov(X, u) = Var(u) = 1, and OLS converges to 0 + 1/2 = 0.5. Because the true effect β = 0, all of that 0.5 is bias. That is a sizable effect of leader behavior built entirely from team performance feeding back into ratings of leader behavior.

To see how this happens for a single team, suppose a sales team has a good quarter because a competitor's product recall sends customers its way, something the leader had nothing to do with. Because the recall affects team performance but is not caused by the leader's behavior, it belongs to u, the part of performance that X does not explain. Let us suppose that the competitor's recall raises this team's performance by two standard deviations, so u = +2 (because u has a variance of 1, one standard deviation is 1 unit). Its performance Y rises by 2, and that success raises the leader's rating X by 2. The leader looks effective because the team did well, not the other way around.

The recall is only one example of what u contains. Every team experiences events outside its leader's control. Some help, like the recall, and some hurt, like losing a major client or a downturn in the team's region, so u is positive for some teams and negative for others. In every case, the event moves team performance and, because performance feeds back into ratings, the leader's rating in the same direction. Across all teams, that produces the covariance of 1 between X and u computed above, which OLS turns into a slope of 0.5 even though leader behavior has no effect on performance.

A more realistic version

In most applications the hypothesized effect is real, and reverse causation inflates it rather than creating it from nothing. Suppose leader behavior does improve team performance (β = .5), performance still feeds back into the leader's rating (α = 1), and u and e again each have a variance of 1. Solving for X now gives

X = (u + e) / (1 − .5) = 2u + 2e, so Var(X) = 8 and Cov(X, u) = 2
plim β̂OLS = β + Cov(X, u) / Var(X) = .5 + 2/8 = .75

The leader's behavior really does help, but OLS overstates its effect by half: it reports .75 when the true effect is .50. The feedback multiplier 1/(1 − αβ) is now 2 rather than 1, because each round of influence between performance and the rating amplifies the next, which doubles how much of the outcome variable's error ends up in X.

Why this causes bias

Whatever pushes Y up feeds back into X. High-X cases are disproportionately those with positive errors in the outcome equation, so the regression conflates the effect of X on Y with the effect of Y on X. This is the textbook case for IV: a variable that has a causal effect on X but does not appear in the equation for Y.

Endogeneity source #3: Measurement error in X

Even purely random error in the measured X is enough to make X endogenous and bias OLS. Suppose a researcher hypothesizes that an employee's conscientiousness (X) is a positive cause of job performance (Y) and measures conscientiousness with a self-report survey. Suppose that X*, the survey score, has two components: the true score X and measurement error w, so X* = X + w. The error is purely random: it has a mean of zero and is uncorrelated with X and with u.

Start from the data-generating model. Performance depends on the true score, not on the survey score:

Y = βX + u,    X* = X + w

The researcher cannot observe X, only X*, so the regression has to use X*. Solving the second equation for the true score gives X = X* − w. Substituting that into the first equation gives the regression the researcher actually runs:

Y = β(X* − w) + u = βX* + (u − βw) so the regression error is u − βw

Nothing about Y has changed; it is the same equation written in terms of X*. The error term in the regression of Y on X* should just be u, the part of performance that conscientiousness does not explain. Instead, it also includes −βw, the measurement error scaled by the effect. Because X* contains +w and the error contains −βw, the two share a component, causing Cov(X*, u − βw) ≠ 0. Using covariance algebra, we can derive that covariance and the value OLS converges to as

Cov(X*, u − βw) = −β·Var(w)
plim β̂OLS = β · Var(X)Var(X) + Var(w)
Show how these are derived

The covariance. Expand the covariance term by term, using the fact that covariance is linear:

Cov(X + w, u − βw) = Cov(X, u) − β·Cov(X, w) + Cov(w, u) − β·Cov(w, w)

The error w is uncorrelated with X and with u, and the true score is uncorrelated with u, so the first three terms are zero. The last is −β·Var(w), because a variable's covariance with itself is its variance.

The OLS limit. The OLS slope converges to Cov(X*, Y) / Var(X*). The numerator is Cov(X + w, βX + u) = β·Var(X), because only the true score is related to Y. The denominator is Var(X) + Var(w), because the true score and the error are uncorrelated. Dividing gives the formula above. The fraction Var(X) / [Var(X) + Var(w)] is the reliability of X*, the share of its variance that is true-score variance.

A concrete case

Let conscientiousness have a real effect on performance (β = .5), give the true score a variance of 1, and give the measurement error a variance of .25. Then Var(X*) = 1 + .25 = 1.25, the reliability of the survey is 1 / 1.25 = .80, and OLS converges to .5 × .80 = .40. Because the true effect β = .5, OLS understates it by .10, or 20%.

That is a sizable underestimate produced by a scale whose reliability many researchers would consider acceptable. OLS would lead us to conclude that a 1-point increase in conscientiousness produces a .40 increase in performance, when the true effect is .50.

To see how this happens for a single employee, suppose an employee's true conscientiousness is one standard deviation above the mean (X = 1), but on the day of the survey they describe themselves generously, so w = +0.5 and their survey score is X* = 1.5. Set u = 0 to keep the arithmetic simple. Their performance depends on their true score, so Y = .5 × 1 = .5. The regression equation in X* predicts .5 × 1.5 = .75, so the error must be −.25, which is −βw. The βX* term gives this employee credit for half a unit of conscientiousness they do not have, so their actual performance falls below what the regression predicts, and their regression error is negative (−.25). Employees whose survey scores are too high end up with negative errors, and that pairing is what makes X* and the error term negatively correlated.

Every employee's survey score contains some error, positive for some and negative for others. Employees whose scores are too high have negative errors in the regression, and employees whose scores are too low have positive ones. Across all employees, that produces Cov(X*, u − βw) = −.5 × .25 = −.125, which, divided by Var(X*) = 1.25, pulls the OLS slope from .50 down to .40.

Why this causes bias

Measurement error adds variation to X* that has nothing to do with Y. The OLS slope is computed by dividing the covariance of X* with Y by the total variance of X*. Only the true-score part of X* contributes to that covariance, because the error part, w, is unrelated to Y. But both parts contribute to the variance, so the denominator is inflated by the error variance while the numerator is not. The slope therefore shrinks toward zero by a factor equal to the reliability of X*. This is why random measurement error in X always biases OLS toward zero, a pattern called attenuation, and why the size of the bias depends on reliability. For the same reason, correcting an unstandardized slope for attenuation means dividing the observed slope by the reliability (Fuller, 1987). For a correlation, the familiar correction divides by the square root of the reliability instead (Spearman, 1904), because a correlation divides the covariance by the standard deviation of X* rather than its variance. IV offers another remedy: a second, independently measured indicator of X can serve as an instrument for X*, because its measurement error is uncorrelated with w.

Endogeneity source #4: Selection

Units choose, or are chosen into, levels of X for reasons tied to their outcomes, as when the most motivated employees sign up for a voluntary sales training program and the outcome is their sales revenue over the following year.

Start from the data-generating model. X is now binary (completed the training or not), Y is next year's sales revenue, and the decision to enroll depends on the same motivation that also drives sales and is therefore part of u:

Y = βX + u,    X = 1 if λu + e > 0, otherwise 0

With a binary X, the OLS slope is the difference in group means:

β̂ = Ȳ1 − Ȳ0  →  β + [E(u | X = 1) − E(u | X = 0)]

When λ > 0, salespeople with high u, those who would sell more regardless, are more likely to enroll, so the bracketed term is positive.

A concrete case

The training has no effect on sales (β = 0). The salespeople who would have posted higher sales anyway, because they are more motivated, are the ones who sign up. The next year, the trained group's average sales revenue exceeds the untrained group's, and OLS reports that revenue gap as the effect of the training.

Why this causes bias

The selection rule puts u inside X. Because X is partly a function of u, Cov(X, u) ≠ 0, for the same reason as in simultaneity.

A related problem: selecting the sample on Y

Now suppose enrollment was random, but the company dismisses any salesperson whose annual sales revenue falls below a quota c, and you can study only the salespeople still on the payroll. Staying employed requires

βX + u > c  →  u > c − βX

If the training works (β > 0), the amount of sales revenue a salesperson must generate from sources other than the training, u, to meet the quota differs by group. Untrained salespeople keep their jobs only if u > c, so the untrained ones who remain are those with unusual motivation, a strong territory, or good luck. Trained salespeople need only u > c − β, because the training carries part of the load, so some trained survivors have quite ordinary u.

Among the salespeople who remain, the untrained group has the higher average u, so the error is negatively correlated with X even though no one chose training based on u. Comparing survivors understates the training's effect on sales revenue, and a modest real effect can vanish. Here the bias runs opposite to the self-selection case, and it is created by the researcher keeping only cases above a threshold on Y.

This is related to the restriction-of-range problem in personnel selection, with one key difference. Selecting cases on the predictor, as when only hired applicants are studied, attenuates correlations but leaves the unstandardized slope unbiased. Selecting cases on the outcome, as here, biases the slope as well, because it makes the retained errors correlated with X.

Why endogeneity has to be dealt with

  • It is not sampling error. More data shrink the standard error around the biased value. A large study yields a narrow confidence interval around the wrong number.
  • It can change the direction, not just the magnitude. Confounding can manufacture an effect where none exists, hide a real one, or flip its sign.
  • Adding control variables helps only with confounders you have measured. Including a confounder as a covariate removes the bias it causes, provided it is measured well. Control variables cannot remove bias from confounders you did not measure, from Y causing X, or from measurement error in X. Reviews of published management and leadership research have found that most studies making causal claims leave these threats unaddressed (Antonakis et al., 2010).
§2 · A STATISTICAL FIX

An instrument isolates the clean part of X

I should begin by saying that the best way to deal with a design flaw is to use a better design. Statistical solutions to design flaws should always take a back seat. That said, sometimes flaws are baked in. If the predictor is, say, an attitude, then I can't really assign people to an attitude condition. As a result, there will always be an endogeneity issue. What follows is a statistical fix, which means that it is better than nothing and worse than a design fix.

An instrument Z is a variable that is correlated with X, usually because it has a causal effect on X, and is related to Y only through X: it has no direct effect on Y and shares no common causes with Y. The variation in X that Z causes is unrelated to u, so this Z-driven portion of X can be used to estimate β1 even when the rest of X is contaminated. Two conditions must hold:

Testable

1. Relevance

Cov(Z, X) ≠ 0. The instrument is correlated with the treatment, strongly enough to matter. Identification requires only this correlation; a causal effect of Z on X is the usual justification but not a requirement. A strong instrument is one that predicts X well, so that the first-stage regression of X on Z has a large R² and a large F statistic. A weak instrument predicts X poorly. Strength matters in two ways: the size of the first-stage relationship determines how much a small violation of exogeneity costs, and the first-stage F, which reflects the instrument's strength and the sample size together, determines whether 2SLS estimates and intervals are reliable.

Only partly testable

2. Exogeneity

Cov(Z, u) = 0. The instrument is uncorrelated with the error term, so it is related to Y only through its relationship with X. In causal terms, this usually means two things: Z shares no unobserved causes with Y, as when it is randomly assigned, and Z has no direct effect on Y (the exclusion restriction). An instrument that fails either condition is said to violate exogeneity, and such a violation is the source of bias in 2SLS.

With more instruments than endogenous regressors, overidentification tests (§4) can check whether the instruments agree with one another, but they cannot confirm that any of them is valid. With one instrument per endogenous regressor, no test is possible, and exogeneity rests on the argument for the design.

With one instrument and one endogenous regressor, the instrumental-variables estimate of β1, written β̂IV, is a ratio of two regression slopes: the slope from regressing Y on Z (the reduced form) divided by the slope from regressing X on Z (the first stage).

How the formula matches the two regressions. Write the two regressions, each with Z as the only predictor. A regression slope is the covariance of predictor and outcome divided by the predictor's variance:

First stage:  X = π0 + πZ + v,    π̂ = Cov(Z, X)Var(Z)
Reduced form:  Y = ρ0 + ρZ + e,    ρ̂ = Cov(Z, Y)Var(Z)

β̂IV is the reduced-form slope divided by the first-stage slope. Var(Z) appears in both denominators, so it cancels:

β̂IV = ρ̂π̂ = Cov(Z, Y) / Var(Z)Cov(Z, X) / Var(Z) = Cov(Z, Y)Cov(Z, X)

So β̂IV, the instrumental-variables estimate of the effect of X on Y, is the covariance of Z with Y divided by the covariance of Z with X. In large samples it converges to the causal effect plus a bias term:

β̂IV = Cov(Z, Y)Cov(Z, X)  →  β1 + Cov(Z, u)Cov(Z, X) If the instrument is truly exogenous, the second term is zero and plim β̂IV = β1: in large samples, the IV estimate converges to the causal effect.

Why the ratio equals the causal effect. Because Z affects Y only through X, every unit of change in Y that Z produces travels through X. If a one-unit increase in Z raises X by 0.5 and raises Y by 0.25, then 0.5 units of X produced 0.25 units of Y, so one unit of X produces 0.25 / 0.5 = 0.5 units of Y.

Where the second expression comes from. The second expression shows what the IV estimate converges to in large samples, and it comes from rewriting the numerator, Cov(Z, Y). Because Y = β0 + β1X + u, the covariance of Z with Y splits into two pieces, Cov(Z, Y) = β1·Cov(Z, X) + Cov(Z, u); the intercept β0 drops out because a constant has no covariance with anything. The first piece is the part of the Z–Y covariance that runs through X, and the second is any covariance between Z and the error term. Dividing both pieces by the denominator, Cov(Z, X), gives β1 + Cov(Z, u) / Cov(Z, X): the true effect plus a bias term. The relevance condition keeps the denominator away from zero, and the exogeneity condition makes the numerator of the bias term zero. Compare the OLS formula in §1. Its bias term has Cov(X, u) in the numerator, and when X is endogenous nothing in the OLS calculation can make that zero. IV replaces it with Cov(Z, u), which a well-chosen instrument does make zero.

Why good instruments matter

IV removes the bias of OLS only if the instrument is good: strong, meaning that it predicts X well, and truly exogenous. The two requirements interact, because a weakness in one magnifies a flaw in the other. If the instrument is slightly invalid (i.e., Cov(Z, u) is small but not zero, because Z has a minor direct effect on Y or a weak link to an omitted cause of Y), the size of the bias in β̂IV depends on the denominator, Cov(Z, X), which measures the first stage: how strongly the instrument moves X. When the first stage is weak, that denominator is close to zero, and dividing by it turns a small violation into a large bias.

To see how much this matters, return to the example above, in which a one-unit increase in Z raised X by 0.5. If Z has a variance of 1, that first-stage slope is also Cov(Z, X) = 0.50. Now suppose the instrument is slightly invalid, with Cov(Z, u) = 0.02. The bias is 0.02 / 0.50 = 0.04, small next to the true effect of 0.5. For comparison, suppose X is endogenous enough that OLS has a bias of Cov(X, u) / Var(X) = 0.30 / 1.50 = 0.20, so OLS converges to 0.70 while IV converges to 0.54. Even though this instrument is slightly invalid, its bias is one fifth the size of the OLS bias, and IV is still much the better choice.

Now let's suppose that, in addition to being slightly invalid, the instrument were also weak, raising X by only 0.05 per unit of Z. Now that small lack of exogeneity produces a bias of 0.02 / 0.05 = 0.40, nearly as large as the effect being estimated and twice the OLS bias. An instrument that is both weak and slightly invalid can therefore produce an estimate more biased than the OLS estimate it was meant to correct, so choosing a strong, convincingly exogenous instrument is crucial to the success of an IV analysis.

Perfect exogeneity is difficult to achieve and can never be fully verified, so most instruments are likely to be at least slightly invalid. Relevance, by contrast, can be measured, and the researcher often has more control over it, for example by designing a more compelling encouragement or collecting a larger sample. Because a strong instrument limits how much a small violation of exogeneity can distort the estimate, choosing a strong instrument is the researcher's best protection against the violations that cannot be ruled out, provided the gain in strength does not come at the cost of a less plausible case for exogeneity.

Two-stage least squares generalizes this to several instruments. Stage 1 regresses X on the instruments and keeps the fitted values X̂. These are each case's predicted value of X from that regression, for example X̂ = π̂0 + π̂1Z1 + π̂2Z2 with two instruments. X̂ is the part of X that the instruments explain. Because the instruments are uncorrelated with u, so is X̂. The rest of X, the first-stage residual X − X̂, holds all of the variation that is correlated with u, and 2SLS discards it. Stage 2 regresses Y on X̂. You can run the two stages as separate regressions and get the correct 2SLS coefficient, but the standard errors from the stage-2 output will be wrong. That regression computes its residuals as Y − β̂X̂, using the fitted values. The correct residuals are Y − β̂X, using the observed X, because that is the variable in the model being estimated. Dedicated 2SLS routines (e.g., ivreg in R, ivregress in Stata) use the observed X and report correct standard errors.

Choosing sets of instruments

When more than one credible instrument is available, an overidentified model, with more instruments than endogenous regressors, has three advantages over a just-identified one.

  • It allows a test. With a single instrument, the exclusion restriction cannot be checked against the data at all. With two or more, the overidentification tests in §4 can ask whether the instruments imply the same value of β, which is the only way the data can speak to exogeneity.
  • It can add precision. If each instrument explains part of the variation in X that the others do not, the first stage is stronger and the 2SLS estimate is more precise. Instruments that add little do the opposite: many weak instruments make the first stage weaker per instrument and pull 2SLS toward OLS.
  • It shows how much the result depends on any one instrument. Reporting the estimate from each instrument on its own lets readers see whether the conclusion rests on a single source of variation.

These advantages depend on what the instruments have in common. The overidentification tests detect only disagreement, so they can catch an invalid instrument only if its bias differs from the others'. Instruments that work through the same mechanism tend to share the same possible violations, such as several lags of one variable or one instrument interacted with different groups. If one is invalid, the others are likely to be invalid in the same direction, so they agree on the same wrong value and the test stays silent. Instruments that work through different mechanisms are each vulnerable to different violations, which makes it unlikely that their biases would match. When instruments like these agree, the agreement is genuinely informative. However, one good instrument is much better than one bad and one good instrument, so only add a second instrument if you can find a good one.

Examples of instruments

Classic instruments include:

  • Quarter of birth as an instrument for years of schooling, in estimating the effect of schooling on earnings (Angrist & Krueger, 1991). Quarter of birth is the quarter of the calendar year in which a person was born: January–March, April–June, July–September, or October–December. Because children start school by a calendar cutoff and may leave school on their 16th birthday, students born early in the year can leave with slightly less schooling than those born late in the year.Why it should be exogenous: the season in which a person is born is essentially a matter of chance with respect to their ability, motivation, and family background, the omitted variables that bias OLS. There is also no obvious reason that being born in March rather than November would affect adult earnings except through the extra months of school.
  • The sex of the departing CEO's firstborn child as an instrument for family CEO succession, in estimating the effect of handing a family firm to a family member rather than an outside professional on firm performance (Bennedsen, Nielsen, Pérez-González, & Wolfenzon, 2007). Using data on successions in Danish family firms, the authors found that firms were more likely to pass to a family member when the departing CEO's firstborn child was a son. The IV estimates showed that family successions sharply reduce operating profitability, a larger decline than OLS suggested.Why it should be exogenous: a child's sex is determined by chance at conception, so it cannot be correlated with the founder's skill, the firm's prospects, or the industry conditions that might also drive both the succession decision and later performance. The exclusion restriction requires that the firstborn's sex affect firm performance only through who becomes CEO, which is plausible but not guaranteed. For example, it would fail if the sex of a founder's children changed family involvement in the business in other ways.
  • Random assignment to an encouragement as an instrument for taking up a treatment, in settings where people cannot be forced to take the treatment. The researcher randomly chooses who receives an encouragement, such as an invitation, a reminder, or a voucher, and each person then decides whether to take part. For example, a randomly selected half of the sales staff receive a personal invitation to the voluntary training program from the selection example in §1. In that example, the outcome (Y) is each salesperson's sales revenue over the following year, the treatment (X) is completing the training, and the most motivated salespeople choose to enroll. Because motivation also raises sales, it is part of u, and OLS overstates the effect of the training. Enrollment (X) is still self-selected and endogenous. It is relevant if invited employees enroll at a higher rate.Why it should be exogenous: the invitation (Z) is assigned by a coin flip, so invited and uninvited employees are alike, on average, in motivation, skill, and territory, and Z cannot be correlated with anything in u. Randomization does not guarantee exclusion, though. The invitation must affect sales only by changing who enrolls, which would fail if, for example, a personal invitation from management motivated employees to sell more whether or not they took the training.

Pairs of instruments

Consider adding a second instrument to the training invitation. The invitation increases enrollment through attention from management, and its most plausible violation is that this attention motivates employees to sell more whether or not they enroll.

  • A good second instrument: distance from the employee's office to the training site. Employees whose offices are farther from the site are less likely to enroll, because attending costs them more time and travel. This mechanism is unrelated to management's attention, and so are its possible violations. The concern with distance is a shared cause, since offices near the training site may be in larger markets where sales are higher, which is addressed by controlling for market size or region. Because the two instruments are vulnerable to different problems, a violation of one would be unlikely to bias the other in the same direction and by the same amount, so the overidentification test has a real chance of detecting it.
  • A bad second instrument: a randomly assigned reminder email from management. The reminder also increases enrollment, but through the same mechanism as the invitation, attention from management. If that attention motivates employees to sell more on its own, it does so for both instruments, so both would be invalid in the same direction. The two would then imply similar wrong values of β, the overidentification test would very likely retain H₀, and the agreement would look like support for instruments that share a single flaw. Randomizing the reminder does not help, because randomization rules out a shared cause but not a direct effect.

The trade-offs of IV: precision and scope

Trade-off 1: Precision

The cost of IV is precision. OLS uses all of the variation in X to estimate β1. 2SLS uses only the part that the instruments explain, X̂, and throws the rest away. Estimating a slope from less variation in the predictor gives a noisier estimate, so the 2SLS standard error is larger. With one instrument and homoskedastic errors, the two sampling variances are approximately

Var(β̂OLS) ≈ σ²un·Var(X),    Var(β̂IV) ≈ σ²un·Var(X)·ρ²ZX
SE(β̂IV) / SE(β̂OLS) ≈ 1 / |ρZX|

The only difference is the squared correlation between the instrument and X, which is the first-stage R². It acts like a reduction in sample size: IV with n cases is about as precise as OLS with n·ρ²ZX cases. If the instrument correlates .50 with X, the IV standard error is about twice the OLS standard error, and matching the precision of OLS takes four times the data. At ρZX = .30, the standard error is about 3.3 times larger and the sample must be about 11 times larger. At ρZX = .10, the standard error is ten times larger and the sample must be 100 times larger. This is another reason that strong instruments matter: a weak instrument not only magnifies any violation of exogeneity, it also leaves the IV estimate so imprecise that even a large sample may not be enough to say much about β1. In the lab below, the reading beside the estimates reports how many times wider the 2SLS interval is than the OLS interval.

This creates a genuine trade-off. OLS is precise but centered on the wrong value; IV is centered on the right value but spread widely around it. When endogeneity is severe, the bias of OLS dominates and IV is clearly better. When endogeneity is mild and the instrument is weak, an OLS estimate with a small bias can land closer to the truth, in a typical sample, than a 2SLS estimate with a large standard error. The Durbin–Wu–Hausman test in §4 asks whether the difference between the two estimates is large enough to justify paying that cost.

Inference when the instrument may be weak: the Anderson–Rubin test

A weak instrument causes a third problem besides bias and imprecision: the usual standard errors and confidence intervals for β̂IV stop working. Because β̂IV divides by an estimated first-stage covariance that can land close to zero, its sampling distribution becomes skewed and heavy-tailed rather than normal. A nominal 95% interval built as β̂IV ± 1.96·SE can then cover the true β far less than 95% of the time, while looking deceptively precise.

The Anderson–Rubin (AR) test (Anderson & Rubin, 1949) avoids the problem by never dividing by the first stage. To test whether β equals some value β0, it subtracts β0X from Y and regresses what is left, Y − β0X, on the instruments. If β0 is the true effect and the instruments are valid, what is left is just the error u plus a constant, so the instruments should explain none of it. The AR statistic is the ordinary F test of the instruments' coefficients in that regression, and its distribution under the null hypothesis is the same whether the instrument is strong or weak.

An AR confidence interval is the set of all values β0 that the test does not reject. With a strong instrument, it is an ordinary interval close to the conventional one, so reporting it costs little. With a weak instrument, it widens, and it can even be unbounded, extending to infinity in one or both directions. An unbounded interval is the honest answer that the data cannot pin down β. With more instruments than endogenous regressors, the AR test checks β = β0 and the exclusion restriction jointly, so an invalid instrument can lead it to reject every value.

AR inference does not make a weak instrument strong. It reports honestly how little a weak instrument reveals. The better remedy is a stronger instrument that is still convincingly exogenous, ideally obtained by strengthening the design, such as a more compelling encouragement, a larger sample, or a more reliable measure of X. Searching among candidate instruments for the one with the largest first-stage F is not a good remedy, because it selects partly on sampling noise and can make 2SLS bias worse (Hall, Rudebusch, & Wilcox, 1996). The usual advice is to do both: seek the strongest valid instrument the design allows, and report AR intervals regardless (Andrews, Stock, & Sun, 2019).

Trade-off 2: Scope

The second trade-off concerns scope: whose effect IV estimates. Everything so far has assumed a single β1 that applies to everyone. In practice effects are often heterogeneous: the training might raise one salesperson's revenue a great deal and another's hardly at all. When effects differ, IV does not estimate the average effect for the whole population. It estimates the average effect for the people whose X was changed by Z, called the local average treatment effect, or LATE (Imbens & Angrist, 1994).

The reason is that the instrument can reveal an effect only where it moves the treatment. Return to the randomized training invitation example and suppose that salespeople fall into three groups:

  • Compliers enroll if invited and do not enroll otherwise. The invitation changes their X.
  • Always-takers enroll whether or not they are invited, perhaps because they are highly motivated.
  • Never-takers do not enroll whether or not they are invited.

Note: The LATE result requires one further assumption, monotonicity: no one is a defier who would enroll without an invitation but refuse because of one. That is why the list has only three groups.

Because the invitation changes enrollment only for compliers, any difference in average sales between the invited and uninvited groups must come from them. Suppose 20% of uninvited salespeople enroll, compared with 50% of invited salespeople. Because the invitation is randomly assigned, both groups contain the same mix of types. The 20% who enroll without an invitation are the always-takers. In the invited group, the always-takers enroll too, along with the compliers, so the extra 30 percentage points are the compliers, and the remaining 50% are never-takers. Suppose also that invited salespeople sell $3,000 more on average than uninvited ones. The IV estimate is $3,000 / 0.30 = $10,000, the average effect of the training for compliers. It says nothing about always-takers, whose enrollment the invitation never changed, and they may benefit more or less from the training than compliers do.

Two practical consequences follow. First, the IV estimate answers a narrower question than OLS appears to: in the training example, the $10,000 estimate is the effect of the training for salespeople who enroll only when invited. It is not the effect for all salespeople, and it is not the effect for the motivated always-takers who would enroll on their own. If the company is deciding whether to send invitations to more of its staff, that is the effect it needs. If it is deciding whether to require training for everyone, including those who would never sign up, it is not.

Second, different instruments might move different people. For example, the salespeople whose enrollment changes in response to the invitation instrument, its compliers, need not be the same salespeople whose enrollment changes in response to some other instrument. A personal invitation from management might move salespeople who respond to attention from their bosses, while a voucher that covers travel to the training might move those for whom cost is the obstacle. Two valid instruments can therefore produce different estimates, because each estimates the training effect for its own group of compliers, and those groups may benefit from the training by different amounts. That also means a significant Sargan test in §4 may reflect heterogeneous effects rather than an invalid instrument.

§4 · TESTING EXOGENEITY

Three questions the data can partly answer

Exogeneity comes up twice in an IV analysis: is the regressor X exogenous (if so, OLS is fine and IV is unnecessary), and are the instruments exogenous? The data can address the second question only indirectly, by checking whether the instruments agree with one another. The first-stage test checks the precondition that makes both answers trustworthy. Each of the three panels below reports one test on the current sample, followed by the answer to its question, which the simulation knows but real data never reveal.

Sensitivity analysis: what if exclusion fails?

Optional. Uses the current sample.

No test can confirm that an instrument is exogenous, so a careful analysis also asks how much the conclusion would change if it were not. This analysis follows the approach of Conley, Hansen, and Rossi (2012). You choose the largest direct effect of each instrument on Y that you consider plausible, in units of Y per standard deviation of Z. In the lab, this direct effect is exactly what the φ sliders set.

For every combination of direct effects between minus and plus that value, the analysis removes the assumed direct effect from Y, re-estimates β by 2SLS, and computes a 95% confidence interval. It then reports the range of those estimates and the union of their intervals, the set of values of β that are consistent with the data under at least one of the assumed violations. If the union excludes zero, the conclusion that X affects Y survives every violation in the range you chose.

§7 · IN PRACTICE

A workflow for using instruments

  1. Make the case for the instrument before you touch the data. Explain convincingly why Z should be strongly related to X, and why X is the only plausible reason that Z would be related to Y. That requires two separate cases: one against a direct effect of Z on Y, and one against a shared cause of Z and Y. Against a direct effect, identify the most plausible way Z could influence Y other than by changing X, and explain why it should not operate. In the training example, the linkage to argue against is that a personal invitation from management might itself motivate employees to sell more, whether or not they enroll in the training. Against a shared cause, identify the most plausible variable that could influence both Z and Y, and explain why it should not. In the training example, invitations might go mostly to stronger offices, which random assignment rules out. No test substitutes for this argument when the model is just-identified.
  2. Report the first stage and the reduced form. Report the instrument coefficients and the first-stage F. With heteroskedastic or clustered errors, use the effective F (Montiel Olea & Pflueger, 2013).
  3. Seek the strongest valid instrument the design allows, and report weak-instrument-robust inference regardless. Strengthen the instrument through the design rather than by searching for the largest first-stage F. Report Anderson–Rubin intervals (explained in §2) alongside the conventional ones, since they remain valid however weak the instrument. In just-identified models, a conventional 5% t-test needs a first-stage F above about 104.7 to have its nominal size (Lee et al., 2022).
  4. If over-identified, report Sargan or Hansen J, and say plainly that it tests agreement among instruments, not their validity. A difference-in-Sargan (C) test can check a suspect subset.
  5. Report OLS beside 2SLS with the Durbin–Wu–Hausman test, so readers can see how much the correction matters and whether it exceeds noise.
  6. Run falsification checks. The instrument should be unrelated to pre-treatment covariates, and unrelated to Y in subgroups where it cannot move X.
  7. Report a sensitivity analysis. Falsification checks can catch some violations of exclusion but cannot measure what an undetected one would cost. Show how the estimate and its interval change under plausible direct effects of the instrument on Y (Conley, Hansen, & Rossi, 2012), or under bounds on how strongly the instrument may be correlated with u (Nevo & Rosen, 2012). The sensitivity panel in §4 runs the first of these on the simulated data.
